# 아이디어 카탈로그

2단계(만들 것 고르기)에서 읽어요. 인터뷰에서 나온 불편과 겹치는 칸을 찾아 후보로 써요. 카탈로그는 출발점일 뿐이에요. 인터뷰에 더 딱 맞는 아이디어가 있으면 그쪽이 우선이에요.

- **모양**: 🔗 링크로 열기 (누가 · 어디서 쓰는지에 따라 ② 또는 ③) · 🖥 내 맥에 설치 (①)
- **난이도** (모두 6시간 안에 끝나는 크기예요)
  - ★ 화면 하나, 입력하고 보여 주기. 재미 요소를 붙일 여유가 있어요.
  - ★★ 화면 두세 개, 모아 보기나 통계가 있어요. 가장 흔한 크기예요.
  - ★★★ 끌어다 놓기, 녹음, 파일 다루기처럼 손이 더 가는 기능이 있어요.
  - ③(가벼운 로그인)을 고르면 Supabase 설정이 더해져요. 크기가 한 칸 커진다고 생각해요.

모든 아이디어는 무료 도구만으로 만들 수 있어요.

## 재미 한 스푼 (선택)

D2에서 "게임처럼"을 고른 사람에게는 재미가 소프트웨어의 정체성이에요. 핵심 기능 수에 세지 않고 4단계 화면부터 같이 만들어요.

- **스트릭**: 며칠 연속 했는지 숫자로
- **배지**: 10회, 30회 달성 배지
- **캐릭터 키우기**: 기록할수록 캐릭터가 자라거나 방에 소품이 생겨요.
  - **이모지로 시작해요** (🐹 🌱 🐰). 무료이고 바로 돼요.
  - 원하면 직접 그린 그림이나 무료 라이선스 이미지로 바꿔요.
  - 유명 캐릭터 그림은 개인 사용에서만 쓰고, 배포한 링크를 남에게 공유하지 않아요.
- **완료 효과**: 체크하면 색종이가 터지는 작은 효과

## 빼는 기능과 대신하는 법

사용자가 원하면 먼저 "그 기능으로 뭘 하고 싶으세요?"를 묻고(`interview-cards.md` G2), 아래 대안을 사용자의 말에 맞춰 제안해요.

| 사용자가 원한 것 | 왜 이번엔 빼나 | 이번 버전에서는 |
|---|---|---|
| 카카오 · 구글 로그인 | 각 회사에 앱 등록, 키 관리가 필요해요 | 닉네임 · 이메일 + 비밀번호 가벼운 로그인 (③) |
| 폰 · 컴퓨터 같은 기록 | (빼지 않아요) | 가벼운 로그인 (③) |
| 친구 · 팀과 같은 내용 같이 보기 | 누가 무엇을 볼지 권한 규칙을 따로 짜야 해요 | 각자 쓰고, "복사해서 보내기" · 폰 공유 버튼으로 나누기. 가족 · 커플이면 "누구 것" 표시 칸을 두고 계정 하나를 같이 쓰기 (비밀번호는 다른 사이트와 다르게, 동시에 고치면 나중에 저장한 쪽이 남는다고 안내) |
| AI가 요약 · 추천 · 위로 | 서버에 비밀 키를 숨겨야 해서 만들 게 두 배가 되고, 내 기록이 외부 회사로 나가요. 무료 한도나 정책이 바뀌면 멈출 수도 있어요 | 정해 둔 규칙으로 정리(기분 색 띠, 많이 쓴 단어, 미리 써 둔 응원 문장) + "Claude에게 물어보기" 복사 버튼 |
| 알림 · 푸시 | 브라우저 · 폰마다 설정이 달라서 처음 만들기엔 복잡해요 | 마감 · 결제일이면 "폰 캘린더에 넣기" 버튼(알람이 들어간 `.ics` 일정 파일 내려받기)으로 폰 캘린더가 대신 알려 줘요. 그 밖에는 열면 첫 화면에 크게 보여 줘요 |
| 구글 캘린더 · 노션 연동 | 외부 서비스 로그인 연결이 필요해요 | 복사 · 파일 내보내기로 옮겨요 |
| SNS · 블로그 자동 발행, 사이트 자동 수집 | 각 서비스 API 연결, 로그인 유지, 규정 확인이 필요해요 | 발행할 글을 채널별로 정리해 "복사" 버튼으로. 수집은 내려받은 파일을 올리면 정리해 주는 방식으로 |
| 링크 미리보기 (썸네일 · 제목 자동) | 서버가 남의 사이트를 대신 열어야 해요 | 태그 색 · 출처 · 메모 한 줄로 카드를 예쁘게 |
| 인증 메일 · 비밀번호 찾기 | 메일 발송 설정이 필요해요 | 비밀번호를 메모해 두라고 안내. 이메일 방식이면 다음에 붙이기 쉬워요 |
| 내 도메인 주소 | 도메인은 돈을 내고 사야 해요 | `○○.vercel.app` 주소를 그대로 써요 |
| 결제 · 유료 판매 | 사업자 · 결제 서비스 설정이 필요해요 | 다음 버전에서 |

**"Claude에게 물어보기" 복사 버튼**: 기록과 요청 문장을 한 번에 복사해 주는 버튼이에요. 사용자는 이미 쓰는 Claude 앱에 붙여 넣기만 하면 돼요. 서버도, API 키도, 추가 비용도 없어요. 예: "이번 주 일기 7개예요. 기분 흐름을 정리하고 응원 한마디 해 줘. (일기 내용)"
