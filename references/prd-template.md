# PRD 양식 (입문자용)

3단계에서 이 양식으로 `PRD.md`를 써요. 빈칸은 객관식 질문으로 채워요. 전체 길이는 화면 두 장 안쪽이 좋아요. 길면 입문자가 안 읽어요. 모양에 해당하지 않는 칸은 지우고, 번호는 다시 매겨요. 양식에 없는 칸이 필요하면 더해도 돼요.

```markdown
# <이름> PRD

| 항목 | 내용 |
|---|---|
| 버전 | v0.1 |
| 작성일 | YYYY-MM-DD |
| 만든 사람 | <git 사용자 이름, 없으면 "나"> |
| 내 컴퓨터 | 맥 / 윈도우 · 설치 제한 있음 / 없음 |
| 모양 | ① 내 맥에 설치 / ② 링크로 열기 (설치 없이 여는 HTML 파일 포함) / ③ 링크 + 가벼운 로그인 |
| 코드 폴더 | <영어-이름>/ |

## 1. 한 줄 소개
<누가> <언제> <무엇을> 하는 소프트웨어. 인터뷰 F에서 확인받은 한 줄을 그대로 써요.

## 2. 왜 만드나
- 지금 불편: <인터뷰 E의 장면 그대로>
- 지금 쓰는 것: <대체하는 서비스 · 그만둔 이유 (C3)>
- 다 만들고 나면: <쓰고 난 기분 (D3)>

## 3. Before → After
- Before: <B3 빈도 × B6 시간. 예: 하루 한 번 × 15분 = 일주일에 약 1시간 45분>
- After (일주일 써 본 뒤 목표): <예: 일주일에 20분 이하 / 놓치는 일 0번>
- 사서 쓰는 게 나은지: 직접 만들기 OK / 일부만 만들기 / 사서 쓰는 게 나음 — <이유 한 줄>

## 4. 핵심 기능 (3개 이하)
1. <기능> — <사용자가 하는 행동 한 줄>
2. ...
3. ...

## 5. 화면
| 화면 | 보이는 것 | 할 수 있는 것 |
|---|---|---|
| 첫 화면 | | |
| 처음 켰을 때 (기록 0개) | 안내 문구 | 첫 기록 추가 버튼 |
| 로그인 (③만) | 닉네임 · 비밀번호 | 가입하기 / 들어가기 |
| <기타> | | |

## 6. 재미 한 스푼 (D2가 "게임처럼"일 때만)
<스트릭 / 배지 / 캐릭터 키우기 중 하나>. 핵심 기능 수에 세지 않고, 4단계 화면부터 같이 만들어요.

## 7. 레퍼런스
- <앱 · 서비스 이름>: <가져올 부분만 콕 집어서. 예: 스와이프 방식만>
- 색 · 분위기: <객관식 답>

## 8. 데이터
- 저장하는 것: <예: 할 일 제목, 완료 여부, 날짜>
- 저장 위치: ① 내 맥 / ② 그 기기의 브라우저 / ③ Supabase (각자 자기 것만 보이게 잠금)
- 로그인 아이디 (③만): 닉네임 / 이메일 · 인증 메일 없음 · 비밀번호 찾기 없음
- 백업 (②만): 파일로 내보내기 · 가져오기 <넣음 / 안 넣음>
- 받지 않는 것: 주민번호, 카드 · 계좌번호

## 9. 안전 규칙 (①만, 핵심 기능 수에 세지 않아요)
- 처음엔 정찰 모드 (목록만 보여 주기)
- 지우기는 휴지통으로만 · 앱 안에서 되돌리기
- 내가 고른 것만 움직이기 (묶음은 개수 확인 후)
- 같은 이름은 덮어쓰지 않기

## 10. 안 만드는 것 (이번 버전)
- 카카오 · 구글 로그인, 결제
- 유료 API · 유료 서비스 (쓴 돈 0원 유지)
- <사용자가 원했지만 미룬 것>

## 11. 다음에 붙일 것
- <미룬 아이디어>

## 12. 확인할 것
- <아직 정하지 않은 것, 만들면서 사용자에게 물어볼 것>

## 13. 완성 기준
- [ ] 핵심 기능이 모두 동작한다
- [ ] 보안 점검을 통과했다
- [ ] 일주일 써 보고 Before → After를 다시 잰다
- ② [ ] 새로고침해도 기록이 남아 있다 · 폰 화면에서도 깨지지 않는다 · 링크로 열린다
- ③ [ ] 폰과 노트북에서 같은 기록이 보인다 · 다른 계정에서는 내 기록이 안 보인다 · 링크로 열린다
- ① [ ] 정찰 모드에서 후보가 맞게 나온다 · 휴지통으로 보낸 걸 되돌릴 수 있다 · 내 맥에 설치돼서 Dock에서 열린다
```

## 채우는 요령

- **한 줄 소개**가 안 나오면: "친구한테 이 소프트웨어를 한 문장으로 소개한다면요?"
- **핵심 기능**이 많이 나오면: 앞 질문으로 4개까지 줄인 뒤, 여러 개 고르기로 "처음 버전에 꼭 있어야 하는 셋을 골라 주세요. 나머지는 '다음에 붙일 것'에 적어 둘게요."
- **레퍼런스**가 안 떠오르면: "이름은 몰라도 돼요. '소개팅 앱처럼 넘기는 거'처럼 어디서 본 기능으로 말해 주세요."
- **처음 켰을 때 화면**은 입문자가 거의 생각 못 하는 칸이에요. Claude가 보기를 먼저 보여 주고 고르게 해요.
- **만든 사람**은 따로 묻지 않아요. git 사용자 이름이 있으면 쓰고, 없으면 "나"로 두고 8단계에서 바꿀 수 있다고 말해요.
