# 내 맥에 설치하는 소프트웨어 (모양 ①)

내 맥의 파일을 정리하거나 옮겨야 하는 아이디어일 때만 써요. 브라우저는 보안 때문에 내 파일을 옮기거나 지울 수 없어서, 이런 아이디어는 맥에 설치하는 소프트웨어여야 해요. 배포도 로그인도 없이 내 맥 안에서만 돌아가요.

시작 전에 사용자에게 알려 줘요.
> "맥에서만 돌아가고, 무료 개발 도구를 하나 써요. 대신 내 컴퓨터 파일을 직접 다룰 수 있어요. 이대로 갈까요, 아니면 파일을 직접 옮기지 않는 링크형으로 바꿔 볼까요?"

## 기술 결정

| 항목 | 선택 | 사용자에게 할 설명 |
|---|---|---|
| 언어 · 화면 | Swift + SwiftUI | 애플이 맥 앱을 만들 때 쓰는 언어예요 |
| 개발 도구 | Command Line Tools (Xcode 없이, 무료) | Xcode 전체(수십 GB) 대신 필요한 도구만 써요. 2단계에서 이미 확인했어요 |
| 앱으로 묶기 | 빌드 스크립트로 `.app` 만들기 + 개인 서명 | 내 맥에서만 쓰는 개인용이라 앱스토어 심사도, 유료 개발자 등록(연회비)도 필요 없어요 |
| 저장 | `~/Library/Application Support/<영어-이름>/` | 맥 앱들이 설정과 기록을 두는 곳이에요 |
| 네트워크 | 쓰지 않음 | 인터넷 없이 내 맥 안에서만 돌아가요 |

폴더 구조는 링크형과 같아요. `PRD.md`, `WORKLOG.md`는 맨 위에 두고, 코드는 `<영어-이름>/` 하위 폴더에 만들어요.

---

## 4단계 · 화면 먼저

1. `<영어-이름>/`에 Swift 패키지를 만들고 SwiftUI로 화면을 그려요. 데이터는 가짜 파일 목록으로 채워요.
2. `scripts/build-app.sh`를 만들어요. 빌드 → `.app`으로 묶기 → 개인 서명까지 해서, 한 줄로 앱을 열 수 있게 해요.
3. 앱을 띄워서 보여 주고 피드백을 객관식으로 받아요. 이 모양은 로컬 링크 대신 앱 창이 미리보기예요.
4. `<영어-이름>/`에서 `git init`으로 저장소를 만들고 첫 커밋을 해요. "커밋은 게임의 세이브 같은 거예요." `git config user.name`이 비어 있으면 이 프로젝트에만 이름 · 이메일을 설정해요 (`--global` 없이, 이메일은 `<닉네임>@users.noreply.github.com`처럼).

## 5단계 · 기능 붙이기: 안전한 순서

파일을 다루는 소프트웨어는 실수 한 번이 사용자 파일을 날려요. 그래서 이 순서를 지켜요. 사용자에게도 왜 이 순서인지 한 줄씩 말해 줘요.

1. **정찰 모드부터**: 첫 기능은 "후보 목록을 보여 주기만" 하는 거예요. 아무것도 옮기지 않아요. 사용자가 목록을 보고 "맞아, 정리할 파일들이야"라고 확인한 다음에 실제 동작을 붙여요.
2. **지우기는 휴지통으로만**: `FileManager.trashItem`만 써요. `removeItem` 같은 영구 삭제는 쓰지 않아요.
3. **되돌리기**: 모든 동작(원래 위치, 원래 이름, 옮긴 위치, 시각)을 기록하고, 앱 안에서 되돌릴 수 있게 해요.
4. **사용자가 고른 것만**: 사용자가 직접 고른 파일만 움직여요. 규칙에 따라 자동으로 지우거나 옮기는 기능은 만들지 않아요.
   - **묶음 고르기는 괜찮아요.** "2025년 3월 캡처 128장"처럼 날짜나 종류로 묶어 보여 주고, 개수와 미리보기를 확인시킨 뒤 한 번에 처리해요. 수백 장을 한 장씩 고르게 하면 쓰지 않게 돼요.
   - 사용자가 "오래된 거 자동으로 다 지워 줘"라고 하면, 사용자의 이야기에서 지우면 안 되는 파일이 섞여 있었던 장면을 짚고 묶음 고르기를 제안해요. 자동 삭제는 PRD의 "안 만드는 것"에 적어요.
5. **이름 바꾸기 · 옮기기도 안전하게**: 같은 이름이 있으면 덮어쓰지 않고 이름 뒤에 ` 2`를 붙여요. 원래 이름은 되돌리기 기록에 남겨요.
6. **건드리지 않는 곳**: `~/Library`, 시스템 폴더, `.app` 파일, 최근 7일 안에 열었거나 수정한 파일, 다운로드 중인 파일(`.crdownload`, `.download`, `.part`).
7. **동기화 폴더**: 구글 드라이브, 드롭박스 같은 동기화 폴더는 후보에서 빼요.
   - 단, **iCloud의 '데스크탑 및 문서' 동기화**를 켠 사람은 바탕화면 자체가 iCloud에 있어요. 이 경우 미리 알려 주고 동의를 받으면 다뤄도 돼요. "휴지통으로 보내면 다른 기기에서도 같이 사라져요. iCloud '최근 삭제된 항목'에서 30일 동안 되살릴 수 있어요."
8. 기능마다 사용자가 직접 써 보고 커밋해요. 테스트할 때는 진짜 파일 대신 테스트용 폴더를 하나 만들어 가짜 파일을 넣고 써요.

**권한 안내**: 데스크탑, 문서, 다운로드 폴더에 처음 접근하면 macOS가 허용할지 묻는 창을 띄워요. 미리 알려 줘요.
> "맥이 '<소프트웨어 이름>이 다운로드 폴더에 접근하려고 합니다' 같은 창을 띄울 거예요. 허용을 눌러 주세요. 그 폴더를 읽을 수 있게 하는 거예요."

## 6단계 · 보안 점검

`security-checklist.md`의 공통 항목과 설치형 항목을 돌려요.

## 7단계 · 배포 대신 설치

인터넷에 올리지 않고 내 맥에 설치해요.
1. 빌드 스크립트로 `~/Applications/<소프트웨어 이름>.app`에 설치해요.
2. Dock에 고정하는 법, Spotlight(⌘ + Space)로 여는 법을 알려 줘요.
3. 원하면 "로그인할 때 자동 실행"을 켜는 법을 알려 줘요.
4. 다른 사람에게 앱 파일을 나눠 주는 건 이번 버전에서 하지 않아요. 애플 공증이 없는 앱은 다른 맥에서 경고가 뜨고, 남의 파일을 다루는 소프트웨어는 더 꼼꼼한 검증이 필요해요.

다른 사람에게 보여 줄 때는 링크 대신 화면 캡처를 붙이게 안내해요.
