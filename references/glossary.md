# 입문자 용어 풀이

처음 나오는 순간에 한 줄로 풀어 줘요. 한 번 설명한 용어는 다시 풀지 않아도 돼요. 사용자가 "그게 뭐야?"라고 하면 아래 설명 뒤에 지금 프로젝트에서 어디에 쓰이는지 한 줄을 붙여요.

| 용어 | 한 줄 설명 |
|---|---|
| 소프트웨어 | 컴퓨터나 폰에서 돌아가는 프로그램 전부예요. 앱도, 웹사이트도, SaaS도 소프트웨어예요 |
| SaaS | 인터넷으로 여러 사람에게 서비스로 제공하는 소프트웨어예요. 노션, 캔바처럼요 |
| PRD | 무엇을, 왜 만드는지 적은 설계도예요 |
| 터미널 | 글자로 컴퓨터에 명령하는 창이에요. Claude Code 입력창에 `!`를 붙이면 바로 명령을 실행할 수 있어요 |
| Node.js · LTS | 웹 소프트웨어를 만들 때 필요한 기본 도구예요. LTS는 오래 안정적으로 지원되는 버전이에요 |
| npm · 패키지 | 남이 만들어 둔 기능 묶음(패키지)을 가져오는 도구예요 |
| 프레임워크 | 소프트웨어를 빨리 만들도록 미리 짜 둔 뼈대예요. 이번엔 Next.js를 써요 |
| 로컬 링크 | 내 컴퓨터에서만 열리는 미리보기 주소예요. 보통 `localhost:3000`이에요 |
| 개발 서버 | 만드는 동안 로컬 링크로 띄워 주는 프로그램이에요. 코드를 고치면 바로 반영돼요 |
| 빌드 | 만든 코드를 실제로 쓸 수 있는 형태로 묶는 일이에요 |
| 린트 (lint) | 코드에 실수가 없는지 훑어보는 맞춤법 검사 같은 거예요 |
| 배포 | 내 컴퓨터에만 있던 소프트웨어를 인터넷에 올려서 링크로 열 수 있게 하는 일이에요 |
| Vercel | 웹 소프트웨어를 인터넷에 올려 주는 서비스예요. 개인용은 무료예요 |
| Supabase | 로그인과 데이터 저장을 맡아 주는 서비스예요. 무료 플랜으로 충분해요 |
| DB | 데이터를 모아 두는 창고예요 |
| RLS | DB에 거는 잠금이에요. 로그인한 사람이 자기 데이터만 보게 막아요 |
| 공개용 키 · 관리자 키 | 공개용 키는 화면 코드에 들어가도 되는 키, 관리자 키는 모든 걸 열 수 있어서 절대 밖에 두면 안 되는 키예요 |
| 환경 변수 (.env.local) | 키 같은 설정 값을 코드 밖에 따로 두는 파일이에요. 인터넷에 올리지 않아요 |
| git · 커밋 | 작업 기록을 저장하는 도구와 저장 한 번이에요. 게임의 세이브처럼 언제든 그 지점으로 돌아갈 수 있어요 |
| GitHub | git 기록을 인터넷에 올려 두는 곳이에요 |
| localStorage | 브라우저 안에 있는 작은 서랍이에요. ②의 데이터는 여기에 저장돼요 |
| API 키 | 외부 서비스를 쓸 수 있게 해 주는 열쇠예요. 새면 남이 내 돈으로 쓸 수 있어서 코드에 넣지 않아요 |
| 보안 헤더 | 브라우저에게 "이 소프트웨어는 이렇게만 써 줘"라고 알려 주는 안전 설정이에요 |
| 반응형 | 컴퓨터와 폰 화면 크기에 맞춰 모양이 바뀌는 거예요 |
| 컴포넌트 | 화면을 이루는 조각이에요. 버튼, 카드, 목록처럼요 |
| JSON | 데이터를 글자로 적는 형식이에요. 백업 파일이 이 형식이에요 |
| Swift · SwiftUI | 애플이 맥 · 아이폰 앱을 만들 때 쓰는 언어와 화면 도구예요 |
| Command Line Tools | 맥에서 개발할 때 필요한 기본 도구 묶음이에요. 무료예요 |
| 스킬 | 자주 하는 일을 한 번 적어 두고 한마디로 불러 쓰는 Claude 작업 설명서예요 |
