# 인터뷰 질문 카드

1단계(인터뷰)와 2~3단계(모양 고르기, PRD)에서 읽어요. 입문자 대부분은 "뭘 만들고 싶어요?"라는 질문에 답하지 못해요. 필요한 게 없어서가 아니라, 불편이 너무 익숙해서 말로 꺼내 본 적이 없기 때문이에요. 그래서 바로 묻지 않고, **고르기 쉬운 객관식과 척도 질문**으로 하루를 훑으면서 불편을 스스로 발견하게 해요.

## 카드는 도구 상자예요

아래 카드는 순서대로 다 물어야 하는 설문지가 아니에요. 사람마다 하는 일도, 불편도, 아는 정도도 달라서 맞지 않는 카드가 꼭 생겨요.
- **안 맞는 카드는 건너뛰어요.** 예: 구독 앱을 안 쓰는 사람에게 C1~C2는 필요 없어요.
- **보기는 그 사람 말에 맞게 바꿔요.** 카드의 보기는 출발점이에요. 앞에서 들은 단어로 다시 쓰면 훨씬 잘 골라요.
- **카드에 없는 질문도 만들어요.** 형식(객관식 · 척도 · 둘 중 하나)만 지키면 돼요.
- **첫 메시지에서 이미 답한 건 다시 묻지 않아요.** 예: "출퇴근길엔 폰, 회사에선 노트북"이라고 했으면 A2, U2는 묻지 말고 "폰과 노트북 둘 다 쓰시는 거죠?"라고 되돌려 확인만 해요.
- **사용자가 이야기를 술술 하면 끊지 말고 들어요.** 객관식은 말문을 여는 도구라서, 말문이 이미 열렸으면 되돌려 말하기와 F 가설 확인으로 바로 가도 돼요.

목표는 카드를 다 쓰는 게 아니라 **숨은 불편 하나와 한 줄 가설**을 찾는 거예요.

## 쓰는 법

- **질문 도구(AskUserQuestion)로 띄워요.** 한 번에 질문 4개까지, 질문마다 보기 2~4개예요. 사용자는 언제든 "기타"에 직접 쓸 수 있어요. 도구가 없으면 번호 목록으로 물어요.
- **여러 개 고르는 질문은 `multiSelect`를 켜고** 질문에 "다 골라 주세요"라고 써요.
- **척도는 4칸이에요.** 가운데(보통)로 도망가지 않게 하려는 거예요.
- **답을 사용자의 말로 되돌려 줘요.** 들은 대로 말해 주면 사용자가 자기 불편을 또렷하게 알아차려요.
- **이유를 붙여서 물어요.** "성격을 정하려고 여쭤봐요"처럼 한마디 붙이면 더 솔직하게 골라요.
- **분량은 대략이에요.** 인터뷰는 보통 객관식 10~15개, 주관식 1~2개면 충분해요. 숫자를 맞추려고 하지 말고, 사용자가 지루해 보이면 줄이고 답이 계속 새로우면 더 물어요.
- **예시는 사용자 이야기에 맞춰 만들어요.** 아래 예시 문장은 형식을 보여 주려는 것이에요. 그대로 읽어 주면 사용자를 특정 아이디어로 끌고 가요.

## A. 몸풀기 (넓은 길)

멘트: "가볍게 몇 가지 골라 주세요. 정답은 없어요."

| # | 질문 | 형식 | 보기 |
|---|---|---|---|
| A1 | 컴퓨터로 주로 어떤 일을 하세요? | 하나 | 문서 · 기획 / 디자인 · 콘텐츠 제작 / 마케팅 · 데이터 / 공부 · 개인 생활 |
| A2 | 만든 소프트웨어는 주로 어디서 열 것 같아요? | 하나 | 컴퓨터 / 폰 / 둘 다 비슷하게 / 아직 모르겠어요 |

## B. 시간 도둑 찾기 (넓은 길)

멘트: "최근 일주일을 떠올려 볼게요. 해 본 걸 다 골라 주세요."

| # | 질문 | 형식 | 보기 |
|---|---|---|---|
| B1 | 최근 일주일 동안 해 본 것 (1) | 여러 개 | 할 일 적고 지우기 / 찾던 걸 다시 찾기 (파일 · 캡처 · 링크 · 메시지 · 다른 기기에 적은 메모) / 자료 모아 두기 / 일정 · 마감 챙기기 |
| B2 | 최근 일주일 동안 해 본 것 (2) | 여러 개 | 돈 계산 · 가계부 / 떠오른 생각 · 일기 쓰기 / 같은 문장 · 양식 반복해서 쓰기 / 습관 · 운동 기록 |

B1, B2를 한 번에 띄워요. 그다음 아래 순서로 좁혀요.

1. 고른 게 **3개 이상이면** "고른 것 중에 **제일 귀찮은 것**은요?"를 먼저 물어요 (하나 고르기). 보기는 고른 것 중 4개까지만 넣고, 나머지는 "기타"로 받아요.
2. 1순위는 "제일 귀찮은 것" 답이에요. 2순위는 남은 것 중 앞에서 말을 많이 한 것을 Claude가 골라 "다음은 ○○ 같은데 맞아요?"로 확인해요. 두 가지 × B3 · B4를 한 번에(질문 4개) 묻고, B5는 다음 묶음(C 카드와 함께)에 넣어요.

| # | 질문 | 형식 | 보기 |
|---|---|---|---|
| B3 | ○○, 얼마나 자주 하세요? | 척도 | 한 달에 한두 번 / 일주일에 몇 번 / 하루 한 번 / 하루 여러 번 |
| B4 | ○○ 할 때 얼마나 귀찮아요? | 척도 | 괜찮아요 / 살짝 귀찮아요 / 꽤 귀찮아요 / 정말 싫어요 |
| B5 | ○○ 하다가 놓치거나 잃어버린 적 있어요? (1순위에만) | 척도 | 없어요 / 한두 번 / 종종 / 자주요 |
| B6 | ○○ 한 번 하는 데 얼마나 걸려요? (1순위에만) | 척도 | 1분 안쪽 / 5분쯤 / 15분쯤 / 30분 넘게 |

**Before 정리**: B3(빈도)와 B6(시간)을 묶어서 "일주일에 약 ○분"으로 되돌려 줘요. 예: "하루 한 번 × 15분이면, 일주일에 1시간 45분쯤 쓰시는 거네요." 이 문장이 PRD의 Before가 돼요.

**점수 내기**: 빈도(1~4) × 귀찮음(1~4), 1순위는 놓침(1~4)을 더해요. 점수가 높은 것을 "1순위 불편"으로 잡고 보여 줘요.
> "들어 보니 '○○'가 제일 자주, 제일 귀찮은 일 같아요. 점수로 치면 1등이에요."

**모으기와 다시 찾기는 다른 불편이에요.** "자료 모아 두기"를 고른 사람에게는 "모을 때가 귀찮아요, 나중에 다시 찾을 때가 귀찮아요?"를 한 번 물어요. 무엇을 만들지가 달라져요.

## C. 돈과 앱 (두 길 공통)

멘트: "이번엔 지금 쓰는 앱 이야기예요. 대신 만들 소프트웨어의 힌트가 여기 많아요."

| # | 질문 | 형식 | 보기 |
|---|---|---|---|
| C1 | 돈 내고 쓰는 앱이 있다면 어떤 종류예요? | 여러 개 | 할 일 · 메모 / 습관 · 건강 / 디자인 · 콘텐츠 / 없어요 |
| C2 | 그 앱 기능 중에 실제로 쓰는 건 얼마나 돼요? | 척도 | 10%도 안 돼요 / 절반쯤 / 대부분 써요 / 잘 모르겠어요 |
| C3 | 써 보다가 그만둔 앱이 있다면, 왜 그만두셨어요? | 여러 개 | 너무 복잡하거나 느려서 / 입력이 귀찮아서 / 정이 안 가서 (안 예뻐서) / 유료로 바뀌어서 |

- C2에서 "10%도 안 돼요"가 나오면 바로 짚어요. "그 10%만 있는 내 소프트웨어를 만들면 딱이겠네요. 어떤 기능을 쓰세요?" (주관식 하나)
- C3는 숨은 불편을 가장 잘 끌어내는 카드예요. 그만둔 이유가 곧 내 소프트웨어의 설계 원칙이 돼요. 예: "입력이 귀찮아서" → 입력은 3초 안에. 좁은 길에서도 꼭 물어요.

## D. 성격 · 이거 아니면 저거 (두 길 공통)

멘트: "이제 성격을 정할 거예요. 더 끌리는 쪽을 골라 주세요."

| # | 질문 | 형식 | 보기 |
|---|---|---|---|
| D1 | 더 끌리는 쪽은요? | 하나 | 빨리 적고 끝내기 / 예쁘게 모아 보기 |
| D2 | 더 끌리는 쪽은요? | 하나 | 조용하고 깔끔한 도구 / 게임처럼 재밌게 |
| D3 | 쓰고 난 뒤 어떤 기분이면 좋겠어요? | 여러 개 | 개운함 · 안심 / 뿌듯함 / 재미 / 위로 · 응원 |

D2에서 "게임처럼"이 나오면 `idea-catalog.md`의 "재미 한 스푼"을 후보에 섞고, PRD의 재미 칸을 채워요.

## E. 장면 하나 (주관식, 두 길 공통)

객관식으로 방향이 잡힌 뒤에 딱 하나만 물어요. 1순위 불편을 넣어서 물으면 답하기 쉬워요.
> "'○○' 하다가 제일 짜증 났던 순간 하나만 떠올려 주세요. 언제, 뭘 하다가 그랬어요?"

막히면 **1순위 불편에 맞춘 예시를 그 자리에서 하나** 만들어 발판으로 줘요. 형식만 참고해요.
- 할 일 → "금요일 오후에 이번 주에 뭘 했는지 기억이 안 나서 주간보고를 30분 붙잡았다"
- 가계부 → "카드값이 생각보다 많이 나와서 어디에 썼는지 앱 세 개를 뒤졌다"
- 습관 → "운동을 3일 하고 기록을 안 해서 며칠 했는지 모르게 됐다"

## F. 가설 확인 (두 길 공통)

인터뷰를 한 줄로 정리해서 척도로 확인받아요. 한 줄은 "누가, 언제, 무엇을, 어떤 기분으로" 형식이에요.
> "제가 이해한 걸 한 줄로 쓰면 이래요. '___'. 얼마나 맞아요?"

| 보기 | 다음 행동 |
|---|---|
| 딱 맞아요 | 2단계로 |
| 거의 맞아요 | "어느 한 단어만 바꾼다면요?" (주관식) 후 2단계로 |
| 반쯤 맞아요 | 어느 부분이 다른지 객관식으로 다시 물어요 (불편 / 쓰는 때 / 성격) |
| 아니에요 | 2순위 불편으로 다시 가설을 세워요 |

바꾼 단어가 빼는 기능(소셜 로그인, 같이 고치기, AI…)에 걸리면, 좋은 아이디어라고 받고 G2로 "그걸로 뭘 하고 싶으세요?"를 물은 뒤 대안을 넣어 가설을 다시 써요.

## G. 특별한 경우

### G1 · 아이디어를 들고 온 사람 (좁은 길)

넓은 시간 도둑 찾기(A, B1, B2)는 건너뛰고, 그 아이디어 안을 파고들어요. 목적은 아이디어 뒤에 숨은 진짜 불편을 찾는 거예요.

| # | 질문 | 형식 | 보기 (아이디어에 맞게 바꿔요) |
|---|---|---|---|
| G1-1 | 그 일에서 제일 귀찮은 순간은요? | 하나 | 모을 때 / 정리할 때 / 다시 찾을 때 / 지울지 말지 고를 때 |
| G1-2 | 그 안에 어떤 게 섞여 있어요? | 여러 개 | (아이디어에 맞춰 3~4개. 예: 스크린샷이면 업무 자료 / 나중에 볼 것 / 진짜 쓰레기 / 개인 사진) |
| G1-3 | 제일 걱정되는 건요? | 하나 | 필요한 걸 지울까 봐 / 찾을 때 못 찾을까 봐 / 정리가 오래 걸릴까 봐 / 딱히 없어요 |

G1-1에서 고른 순간에 B3 · B4 척도를 물어요. **G1-1(귀찮은 순간)과 G1-3(걱정)이 다른 곳을 가리키면 두 곳 모두에** B3 · B4를 한 번에(질문 4개) 물어서 점수를 비교해요. 처음 말한 아이디어와 다른 곳에서 점수가 높게 나오면 그대로 보여 줘요.
> "처음엔 지우는 앱을 말씀하셨는데, 점수로는 다시 찾을 때가 훨씬 아프네요. 둘 다 담을 수 있게 생각해 볼게요."

### G2 · 빼는 기능을 원하는 사람

거절부터 하지 않아요. 그 기능으로 하고 싶은 걸 먼저 물어요.

| # | 질문 | 형식 | 보기 |
|---|---|---|---|
| G2-1 | AI가 해 줬으면 하는 건요? | 여러 개 | 길게 쓴 걸 짧게 정리 / 흐름 · 패턴 보여 주기 / 위로 · 조언 한마디 / 다음에 할 일 추천 |
| G2-2 | 같이 쓰면 좋은 점은요? | 여러 개 | 서로 응원하기 / 같은 자료 같이 보기 / 보고 · 공유 전에 미리 보여 주기 / 일 나눠서 하기 |
| G2-3 | 로그인이 필요한 이유는요? | 하나 | 폰과 노트북에서 같은 기록 / 나만 보게 잠그기 / 여러 명이 각자 쓰기 / 잘 모르겠어요 |
| G2-4 | 알림으로 받고 싶은 건요? | 하나 | 마감 · 결제일 전에 미리 / 매일 정한 시간에 습관 챙기기 / 오래 안 열면 한 번 / 잘 모르겠어요 |

G2-4에서 "마감 · 결제일 전에 미리"를 고르면 **폰 캘린더에 넣기**(알람이 들어간 일정 파일 내려받기)가 좋은 대안이에요. 폰 캘린더가 대신 알려 줘요. "앱을 열어야 알면 또 까먹어요"라는 사람에게 "열면 크게 보여 주기"만으로는 부족해요.

답을 받으면 "원하신 마음은 그대로, 방법만 가볍게" 표를 보여 줘요. 표 내용은 사용자의 답에 맞춰 써요. 형식 예시:

```
| 원하신 것 | 이번 버전에서는 | 다음 버전에서 |
|---|---|---|
| AI가 한 주를 정리해 줬으면 | 기분 색 띠 · 많이 쓴 단어 · 정해 둔 응원 문장 + "Claude에게 물어보기" 복사 버튼 | AI 연결 |
| 친구랑 서로 응원 | "응원 요청 보내기" 버튼 (폰 공유 기능으로 카톡에 보내기) | 같이 보는 피드 |
```

AI를 빼는 이유는 이렇게 설명해요. "AI를 붙이려면 서버에 비밀 키를 숨겨야 해서 만들 게 두 배가 되고, 내 기록이 외부 회사로 나가요. 무료 한도나 정책이 바뀌면 갑자기 멈출 수도 있고요." 사람들은 "내 기록이 밖으로 나간다"는 이유에 가장 잘 수긍해요.

### G3 · 큰 자동화를 원하는 사람

"SNS 자동 발행", "CS 응대 자동화", "업무 전부 자동으로"처럼 여러 서비스를 잇는 큰 흐름을 말하는 사람이 많아요. 큰 흐름은 이 다음 단계에서 본격적으로 만들고, 오늘은 워밍업이에요. 그렇다고 이야기를 흘려듣지 않고, **흐름을 칸으로 나눠 한 칸을 고르게** 해요. 내가 원하는 자동화와 이어진 작은 것을 만들면 워밍업도 더 의미 있어요.

| # | 질문 | 형식 | 보기 (흐름에 맞게 바꿔요) |
|---|---|---|---|
| G3-1 | 그 흐름에서 지금 손이 가장 많이 가는 칸은요? | 하나 | 자료 모으기 / 정리 · 분석하기 / 글 · 문서 만들기 / 올리기 · 보내기 |
| G3-2 | 그 칸을 지금 어떻게 하고 계세요? | 여러 개 | 여기저기 복사해서 붙여 넣기 / 엑셀 · 시트에 손으로 정리 / 매번 처음부터 새로 쓰기 / 사이트를 하나씩 열어서 확인 |

설명: "말씀하신 자동화는 과정에서 본격적으로 만들 거예요. 오늘은 워밍업으로, 그중 손이 제일 많이 가는 한 칸을 작은 소프트웨어로 만들어 봐요. 나머지 칸은 나중에 하나씩 이어 붙이면 돼요."

이 칸을 무료 · 외부 연동 없이 만드는 방법은 대부분 **"붙여 넣거나 파일을 올리면 → 정리해서 → 복사 · 내보내기"** 모양이에요. `idea-catalog.md`의 "7. 업무 반자동화"를 봐요. 결과를 "복사" 버튼으로 내보내면, 올리기 · 보내기는 사람이 한 번만 붙여 넣으면 돼요.

G2-3에서 "폰과 노트북에서 같은 기록", "나만 보게 잠그기", "여러 명이 각자 쓰기"가 나오면 가벼운 로그인(모양 ③)으로 바로 풀 수 있어요. 빼는 기능이 아니라고 알려 줘요.

## U. 사용 환경 (2단계 모양 고르기)

세 질문을 한 번에 띄워요. 멘트: "이제 어떤 모양으로 만들지 정할게요. 누가, 어디서 쓸지만 알려 주세요."

| # | 질문 | 형식 | 보기 |
|---|---|---|---|
| U1 | 누가 쓰나요? | 하나 | 나 혼자 / 몇 명이 각자 자기 기록으로 / 여러 명이 같은 내용을 같이 |
| U2 | 어디서 열어요? | 하나 | 이 컴퓨터에서만 / 폰과 노트북 둘 다 / 주로 폰 |
| U3 | 내 컴퓨터 파일을 정리하거나 옮겨야 하나요? | 하나 | 네 / 아니요 / 잘 모르겠어요 |

윈도우 사용자에게는 ①(맥 전용)을 보기에서 빼고, U3도 "파일을 직접 옮기거나 지워야 하나요?"로 물어서 ②의 대안(정리 체크리스트, 이름 규칙 만들기)을 안내해요.

추천 규칙 (SKILL.md 2-2 표와 같아요)
- U3 "네" + 맥 → **① 내 맥에 설치**
- U1 "몇 명이 각자", U2 "폰과 노트북 둘 다", U2 "주로 폰"(특히 아이폰) → **③ 링크 + 가벼운 로그인**
- 나머지 → **② 링크로 열기**
- U1 "여러 명이 같은 내용을 같이" → G2-2로 무엇을 원하는지 묻고, ③ + "복사해서 보내기"나 "계정 하나를 같이 쓰기"를 제안. 각자 계정으로 같은 내용 보기는 다음 버전이라고 설명
- U3 "잘 모르겠어요" → "만들 것이 파일을 직접 옮기거나 지워야 하나요, 아니면 정보를 적고 보는 건가요?"로 한 번 더 물어요

추천을 말한 뒤 세 모양을 보기로 띄워서 사용자가 최종으로 골라요. 추천 모양에 "(추천)"을 붙여요.
