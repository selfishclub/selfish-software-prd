## 이렇게 나온 PRD.md

```markdown
# 경쟁사 캡처 정리기 PRD v0.1
- 만든 사람: 민지 / 날짜: 2026-10-17 / 내 PC: Windows (회사, 설치 제한 있음)

## 1. 한 줄 소개
하루 스무 장씩 찍는 경쟁사 광고 캡처를 회사명 태그로 정리해 주는 내 PC 전용 페이지

## 2. 왜 만드나
파일 이름이 전부 "스크린샷 날짜"라서, 나중에 어느 회사 광고인지 못 찾는다

## 3. Before → After
- Before: 바탕화면에 쌓아 두고 주 1회 손으로 정리(약 40분) + 하루 몇 번 찾기(약 5분)
- After: 주말 정리 10분 이하
- 사서 쓰는 게 나은지: 규정 업데이트나 외부 데이터가 필요 없는 일 → 직접 만들기 OK

## 4. 핵심 기능 (3개 이하)
1. 사진마다 회사명 · 채널 태그 붙이기
2. 태그 기준으로 폴더 옮기기 (옮기기 전에 목록 보여주고 확인받기)
3. 회사명으로 검색

## 5. 화면
- 모양: ② 링크로 열기 — 설치 없이 HTML 파일 하나를 더블클릭
- 흐름: 스크린샷 폴더 고르기 → 사진마다 태그 → [정리하기] → 목록 확인 → 옮기기

## 8. 데이터
- 사진: 문서/경쟁사캡처/{회사명}/
- 태그 목록: 문서/경쟁사캡처/태그.csv
- 외부로 보내는 것: 없음

## 10. 안 만드는 것 (이번 버전)
로그인 · 여러 사람이 같이 쓰기 · 모바일 · 원본 삭제

## 11. 다음에 붙일 것
날짜별 보기 · 복사한 내용 기록 · 같은 양식 채우기

## 13. 완성 기준
캡처 20장을 태그 붙여 정리했을 때 원본이 하나도 사라지지 않고, 회사명 검색으로 바로 찾아진다
```

> 6 · 7 · 9 · 12장은 민지의 경우 해당이 없어 비워 뒀어요. 실제 양식은 [references/prd-template.md](../references/prd-template.md)를 따라요.
