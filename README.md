# 🧽 나만의 소프트웨어 PRD (selfish-software-prd)

> **고르기만 하는 인터뷰 → 매일 쓰고 싶은 나만의 소프트웨어 하나 완성.**
> 길어도 6시간 안에 끝나고, 돈은 Claude Code 구독료 말고는 0원이에요.

바이브 코딩이 처음이어도 괜찮아요. Claude가 옆자리 선배처럼 "지금 뭘 하는지 → 추천 → 고르실래요?"를 말해 주면서 기획부터 완성까지 같이 가요.

## 만든 의도

**셀피쉬클럽 젬마와 비비안이 함께 만들었어요.**
셀피쉬클럽 소식 · 단톡방 · 교육 문의는 맨 아래 **「만든 곳 — 셀피쉬클럽」**에 모아 뒀어요.

스폰지클럽 4기 「나만의 소프트웨어 만들기」를 위해 처음 만들었고, 스폰지클럽 크루만이 아니라 셀피쉬클럽 멤버, 그리고 처음 무언가를 만들어 보려는 누구나 내려받아 쓸 수 있게 공용판으로 열어 두었어요.
뭘 만들지 몰라도 고르기만 하면서 정하고, 설계도(PRD)를 쓴 뒤, 내 컴퓨터에서 매일 쓰는 작은 소프트웨어 하나를 끝까지 완성하는 게 목표예요.

**이 스킬은 워밍업이에요.** 콘텐츠 자동 발행, CS 응대 자동화 같은 큰 자동화는 이 다음 단계에서 본격적으로 만들어요. 그 전에 작은 소프트웨어 하나로 기획부터 배포까지 한 바퀴를 직접 돌아 보면서 손에 익히는 단계예요. 거창하지 않아도 돼요. 매일 쓸 작은 것 하나면 충분해요.

| 단계 | 하는 일 |
|---|---|
| 0 | 시작 인사 · 준비 확인 |
| 1 | 인터뷰: 보기에서 고르고, 귀찮은 정도를 매기면서 내 불편 찾기 |
| 2 | 만들 것 고르기 + 누가 · 어디서 쓸지로 모양 고르기 |
| 3 | PRD 쓰기: 설계도 |
| 4 | 화면 먼저: 로컬 링크로 미리보기 |
| 5 | 기능 붙이기: 하나씩 직접 눌러 보며 |
| 6 | 보안 점검 |
| 7 | 배포 · 설치 |
| 8 | 마무리: 작업 기록 · 공유용 요약 |

중간에 쉬었다 와도 되고, 오늘 다 못 하면 다음에 이어서 하면 돼요.

## 어떤 소프트웨어를 만들어요?

**나한테 필요했던 소프트웨어**예요. 구독료 내고 쓰던 앱에서 내가 쓰는 기능만 쏙 빼서 만들거나, 매일 하는 귀찮은 일을 덜어 주는 거요.

예시: 오늘의 딱 3가지, 습관 도장판, 구독료 정리판, 링크 보관함, 하루 한 줄 일기, 콘텐츠 캘린더, UTM 링크 생성기, 스크린샷 정리…

### 모양은 세 가지 중 하나

누가, 어디서 쓸지 세 가지만 답하면 Claude가 추천해 주고, 최종 선택은 내가 해요.

| 모양 | 이럴 때 | 여는 방법 |
|---|---|---|
| ① 내 맥에 설치 | 내 컴퓨터 파일을 정리하거나 옮겨야 해요 (맥만) | Dock에서 클릭 |
| ② 링크로 열기 | 혼자, 한 기기에서 써요 (회사 컴퓨터라 설치가 막혀 있으면 HTML 파일 하나로) | 링크 또는 더블클릭 |
| ③ 링크 + 가벼운 로그인 | 폰과 노트북 둘 다 써요 / 몇 명이 각자 써요 | 링크 + 닉네임 · 비밀번호 |

### 지키는 세 가지

- **복잡한 기능은 빼요.** 카카오 · 구글 로그인, 결제, AI API, 외부 서비스 연동은 다음 버전으로 미뤄요. 닉네임(또는 이메일) + 비밀번호로 하는 가벼운 로그인은 돼요. 인증 메일은 안 보내요.
- **보안은 지켜요.** 배포 전에 점검표를 돌려요. 로그인을 쓰면 "각자 자기 기록만 보이는지" 직접 확인해요.
- **무료 도구만 써요.** 카드 등록이 필요한 서비스, 유료 API, 도메인 구매는 하지 않아요.

## 설치 (3분)

**가장 쉬운 방법** — Claude Code에 이 주소와 함께 말하면 돼요. 맥 · 윈도우 모두 같아요.

```
https://github.com/selfishclub/selfish-software-prd
이 스킬을 내 ~/.claude/skills/selfish-software-prd 에 설치해줘.
```

설치가 막히면 → `https://github.com/selfishclub/selfish-software-prd 의 SKILL.md 를 읽고 그대로 진행해줘`

**직접 하는 방법** — 이 레포를 Claude 스킬 폴더에 내려받으면 돼요.

**맥**
```bash
git clone https://github.com/selfishclub/selfish-software-prd ~/.claude/skills/selfish-software-prd
```

**윈도우** (PowerShell)
```powershell
git clone https://github.com/selfishclub/selfish-software-prd "$env:USERPROFILE\.claude\skills\selfish-software-prd"
```

이미 설치했는데 새 버전으로 바꾸고 싶으면 → `~/.claude/skills/selfish-software-prd 를 최신 버전으로 업데이트해줘 (git pull)`

설치가 됐는지 보려면 Claude Code 입력창에 `/selfish-software-prd`를 쳐 보세요.

## 시작하기

1. **빈 폴더**를 하나 만들어요. 이름은 한글이어도 괜찮아요.
2. Claude Code에서 그 폴더를 열어요. 시작한 뒤에 폴더를 바꾸면 대화가 새로 시작되니, 처음에 맞춰 두세요.
3. 이렇게 말해요.

> "/selfish-software-prd 나한테 필요한 소프트웨어 하나 만들어 보고 싶어"

이렇게만 말해도 시작돼요.

> "뭘 만들어야 할지 모르겠는데, 하나 완성해 보고 싶어"
> "구독료 내고 쓰는 습관 앱 대신 내 거 만들어 보고 싶어"
> "바탕화면 스크린샷 정리해 주는 거 만들고 싶어요"
